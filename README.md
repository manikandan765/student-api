# Student Management API

A simple and fast RESTful API built with **Python** and **FastAPI** to manage student records.

## Features
- Create, Read, Update, and Delete (CRUD) student records.
- Automatic interactive API documentation (Swagger UI).
- In-memory database for quick testing.
